강의별 Studio 사용 판정

hypeproof studio quality dash board

이 페이지는 강의 오픈 조건이 아니다. 각 강의에서 HypeProof Studio를 사용해도 되는지 강의별로 판정하는 운영 대시보드다. 강의가 정해지면 단일 준비 페이지가 생기고, GitHub 이슈, 체크리스트, 증거 리포트, 리뷰 상태가 모두 그 강의 단위로 묶인다.

Red

단일 준비 페이지

모두가 같은 곳을 본다. 다운로드 링크, 토큰 발급, 세션 열기, 커리큘럼, 체크리스트, 리포트, GitHub 이슈가 강의별로 하나에 모인다.

1

이 강의에서 Studio를 사용하기 위한 준비 상태만 본다. 다른 강의, 다른 링크, 다른 문서를 섞지 않는다.

강의별 GitHub 이슈

강의 날짜가 정해지면 강의명-날짜 prefix로 G1/G2/G3 이슈가 발행된다. 각 이슈에는 담당자, 완료 예정일, 리포트, 리뷰 상태가 붙는다.

Studio 사용 게이트

체크는 강의별로 닫힌다. 한 강의에서 통과했다고 다른 강의가 자동 통과되는 것은 아니다.

보고서와 리뷰

보고서는 “여기 적어둔 설명”이 아니라 강의별 증거 파일이다. 각 리포트가 올라가고 AI 또는 사람이 리뷰해야 Green으로 간다.

강의 준비판

현재 선택된 강의 기준으로 Red/Yellow/Green 전환 예정일을 잡는다. 날짜 없는 Red/Yellow는 관리되고 있는 상태가 아니다.

Green 전환 계획
한 줄 정의: 이 페이지는 “강의를 열어도 되는가”가 아니라 “이 강의에서 HypeProof Studio를 써도 되는가”를 판정한다. 강의별 단일 페이지, GitHub 이슈, 체크리스트, 리포트, AI/사람 리뷰가 모두 있어야 Studio 사용 가능이다.
